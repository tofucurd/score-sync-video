# 固定视觉与封面

背景#FAF8F1；思源宋体Light300/Regular400/Medium500，随包附OFL许可证。原生音乐符号保留Verovio字形；说明文字不换系统字体。中文乐器标签必须保留独奏/分部含义。

3840×2160工作画布；固定阅读线x1344（宽度35%），蓝#287D9F，置于音乐字形背后。谱面仅一列，多声部从上到下，横向自然流动。时间曲线通过已审采样节点和谱面几何节点，PCHIP仅平滑空间运动、不改变音符时间。帧状态由绝对源时间计算，不靠上帧累计。

高亮main#C94732；purple#8650B6；green#27835D；ochre#AA7200。饱和且可辨，不与蓝游标混淆。对每个实际发声音符的完整显示区间执行，高亮符头、对应符干/符尾/附点，不能遗漏其他发声音符。共享符干依成员最高权重着色，原生几何不放大不改形。延音身份保持。包络ease=6u⁵−15u⁴+10u³，区间内淡入取8.33ms与音长10%的较小值，淡出取100ms与音长30%的较小值。

声部自然集合进出用约4s预留/渐变，不因瞬时休止隐藏。跨谱表依赖连接的行保持刚性间距；独立组之间压缩空白并平滑移动，连接符同步更新。新乐章开始发声时必须显示新谱，不能机械地等到开场0.85s后才出现。导航两级常驻；标签和活动状态变化须连续，不突然替换小卡。

声部布局：每组边界由整章音域、符干和加线留白固定计算；同一4秒权重同时控制透明度与空间占用，空间权重为透明度权重的平方根。跨谱表组合内部保持刚性。没有另一套延迟释放的旧布局包络，不能在声部出现后再启动第二轮展开。

封面：16:9 3840×2160，4:3 2880×2160，各自重新排版。标题、作者、演奏信息、“曲谱同步”与罗马编号按已定风格保持视觉层级；“曲谱同步”醒目蓝色，编号细字重并适应位数。无编号留空，不添加虚构编号。不用“完整”，不使用“xxx·xxx”说明尾缀。

真实谱例取当前作品可辨乐句，与视频共用原生SVG、游标、高亮和字体。不能用其他作品谱例当装饰，不能凭空绘制假谱。两种比例都保留同一乐句完整意义，不拉伸、不直接裁掉声部。输出独立SVG（嵌字体）、PNG、JPG；检查长中文标题、罗马数字宽度、演奏者和乐团名称不会遮挡。

## 封面配置与通用入口

`covers` 和 `preview` 都经过 `covers.build_cover_specs`，默认采用已定稿的 `paper` 模板。该函数只组装场景数据，可在不启动浏览器的检查中调用；实际输出由原 `run_browser(..., 'cover')` 执行。封面与视频共用当前项目的原生谱面和事件身份。

在 `project.json` 填写如下字段。这里的小节号是源文件顺序编号；`occurrence` 选择实际反复路线中的第几次出现，`sample_q` 是展开路线的四分音符位置。两比例必须都包含该高亮时刻，选中的小节必须连续。

```json
"cover": {
  "layout": "paper",
  "first_measure": 1,
  "last_measure": 8,
  "occurrence": 1,
  "aspect_ranges": {"16x9": [1, 8], "4x3": [1, 6]},
  "staves": ["P1:1", "P2:1", "P3:1"],
  "sample_q": 0.5,
  "words": {
    "composer_en": "COMPOSER",
    "composer_zh": "作曲家",
    "performer_zh": "演奏者",
    "ensemble_zh": "乐团",
    "performer_en": "PERFORMER",
    "ensemble_en": "ENSEMBLE",
    "work_type_en": ""
  }
}
```

这是格式示例，需按实际谱源选择存在的连续小节、声部和高亮位置。`words` 的六个署名字段均须给出；可选`work_type_en`为空时不显示作品类别，非空时显示该字符串；确实没有某项署名时留空字符串，不猜名字。文字会在字体子集生成前加入字库，避免中文译名回退到系统字体。数字取 `work.number` 并转罗马数字，作品中文标题取 `work.title`。封面通常选三条能辨认主题与伴奏的声部，使用当前乐谱原生内容；没有发声内容的假装饰行不能代替真实谱例。`native_excerpt_builder`、`provenance` 不是可执行配置字段，通用流程不依赖它们。

## 有依据的局部排版覆盖

源谱正确、排版仍发生碰撞时，保留原 MusicXML，仅使用明确绑定源哈希的覆盖文件：

- `movement.engraving_overrides` 指向 JSON，在临时排谱 MusicXML 上修正休止符的 `rest/display-step`、`rest/display-octave`。每项包含稳定 `source_id`、完整 `before_note_xml` 和 `[before, after]` 变化。只改变显示提示，展开到该源事件的所有实际反复；完整事件身份不符则停止。
- `movement.layout_overrides` 指向 JSON，在隐藏墨迹修复后修正原生 SVG 中指定 `dir` 的直接 `text` 的 `x`。清单要求 `source_score_sha256`、`input_svg_sha256`、`output_svg_sha256`、原文字与前后坐标。无法命中同一源和同一几何时重新检查，不把旧坐标强套新谱。

两种文件均采用 `schema: 1`，操作放在 `operations` 数组；项目路径由 `load_project` 解析。`prepare_score` 自动保存临时 `engraving.musicxml` 和覆盖报告，最终视频和封面使用修正后的同一 `score.svg`。每份覆盖只能用于其校验绑定的源和几何。

## 当前排版实现补充

谱面纵向边界依据实际音符音域与符干、加线余量计算，不能仅用五线谱边界；狭窄导航段不挤入超宽标签，当前两级名称始终单独显示。封面谱例视口须包含最下声部力度等符号，不裁成残点。帧状态缓存必须支持倒序访问，不改变音符区间和高亮结果。

同步显示修订：蓝线的每拍位置采用可见实际演奏音头的中位主列，排除休止、提示音和装饰音，避免和弦避碰音头或居中全小节休止误导定位；不移动原谱合法错开音头。音符高亮淡入不超过8.33ms或音长10%，不得因淡入把快速起音视觉上推迟。此项不替代实际录音对齐验证。

双层导航整体采用统一模块 `scripts/score_sync/navigation.py`，不能只模仿指针而另画排版。3840画布中，底板x0/y1834/w3840/h326，纸色#faf8f1；两行top1848/2000，轨道x144/w3552/y1950及2102，高12px。每个相邻段之间保留8px纸色留白；底层必须为#faf8f1，不能用连续灰底把缝填回去。仅段与段之间留缝，整条两端不额外缩短。各段底色#d3d0c7，当前段整段#287D9F；不添加累计已播放填充或浅蓝剩余填充。6px宽40px高蓝指针相对轨道y=-15..25，无箭头/描边。

每行独立左对齐显示当前结构名称，x144、baseline=top+39、42px Regular、#263c41；裁切框x144/y=top-6/w3552/h58。非当前段的标签在各段中心、baseline=top+83、36px Regular、#827e72，位于轨道上方；当前段不重复显示标签。宽度按原字体测量，超出segment_width-22则尝试short_label，仍放不下才省略该非当前标签；标题完整显示。去除文字中的“·”及其后缀。导航中不增加乐章长标题或右上父子合并小标题；乐章身份由既有左上角短标签提供。

段落边界由当前作品的冻结alignment投影到录音本地sample；首段起点为0，末段覆盖原音频末尾。主条范围是完整乐章sample域，副条是当前父段sample域。段宽、指针均按真实样本比例，不能用q/拍数比例代替实际时间比例。段落名称和反复路线属于当前作品。

父段、子段切换均采用0.6秒quintic缓动，背景段层交叉淡化；文字先退后入，各半程错开，当前标题偏移最多10px、非当前标签偏移最多5px。同一时间域指针连续运行，换父域时旧指针停在旧域终点淡出、新指针按新域当前sample淡入。乐章换场采用同一navigation_states的0.85秒previous_nav路径，不能再次在scene层叠乘导航透明度。完整模块的参考等同性检查涵盖状态、实际SVG、字体、稳态、子段/父段/乐章边界，不仅检查纯蓝tick存在。

左上角乐章标识：在现有留白中以思源宋体Regular小字显示“第一乐章”等短标签，当前3840画布x72/y64、36px、#59645F；不增加顶栏、不缩放或平移谱面/声部/双层导航、不使用背景卡片。短标签必须纳入字体子集，乐章场景切换沿用连续过渡。

乐章换场采用分阶段滑动：quintic smoothstep缓动，旧谱0.4s向左最多48px并淡出，再由新谱0.45s从右侧48px滑入并淡入。只平移谱面world，纸底、蓝阅读线和声部标签的横坐标固定；标签随对应谱面淡化。导航轨道和指针在0.85s内交叉淡化，文字前后半程分开退入，主标题上下偏移最多10px，其余导航文字最多5px，避免两套文字叠印。新谱必须在第一个发声音符前就位；若录音开头不足0.85s，将换场起点提前到已有乐章间静音内，不能延迟音符或修改音频。检查前章末音和后章首音，不能无依据把换场移入仍在演奏的区间。
