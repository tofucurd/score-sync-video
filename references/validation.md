# 工具包验证与作品验收

开发验证：运行`python -m pytest tests -q`、`node --check scripts/browser_render.mjs`和`python scripts/check_package.py`。测试使用合成数据，不依赖特定作品或个人工作目录。发布验证摘要见`validation-results.json`。

测试覆盖有理数谱位、移调、反复身份、cue与跨谱表、原生符号绑定、连续对齐、精确锚点、装饰音归属、音频样本、章节标题、封面场景配置、输入变化守卫、授权、分块和清理。无渲染场景测试不代替实际编码图像检查。

维护者修改组件后运行`scripts/release_manifest.py`刷新版本清单，再检查实际文件指纹。新增依赖或工具版本要记录验证范围。CI绿灯和合成信号正确都不能证明某一录音的同步精度。

作品验收时，三名真实审阅者分别查看同一完整方案和相同输出，检查发声声部遗漏、时间误差、跨谱表关系、配色、标签过渡、字体、封面和原声。发现问题后修正并检查相关区间，不用低分辨率掩盖缺陷，也不固定机械重复检查次数。

历史时间图回放、自动匹配候选和独立声学测量分别记录。被混合声部遮蔽的物理起音不可假称唯一可测。完整交付检查通过后及时交付。
